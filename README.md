# Hi, I'm Spencer

I'm a computer science graduate student at Georgia Tech based in Anaheim, California. I build and test C++ and Python software, maintain a Linux home lab, and am collaborating with a team on a MicroPython game for a Thumby Color handheld as a current course project.

My communications background helps me explain technical work and collaborate across disciplines. My repositories emphasize reproducible builds, tests and clear documentation of what each project currently does.

## C++ and systems projects

- **[C++ Telemetry Monitor](https://github.com/Spencer695/cpp-telemetry-monitor)** — An AI-assisted C++17 learning project with real TCP sockets, separate receiving and processing threads, a bounded queue, an optional Qt 6 Widgets dashboard, validated simulated readings, CMake and Linux CI.
- **[IEEE 754 Floating Point Converter](https://github.com/Spencer695/IEEE-754-Assignment)** — Reconstructs single-precision floating-point values from sign, exponent and mantissa fields. Includes explicit boundary cases, deterministic bit-pattern tests, CMake and Linux CI.
- **[RPN Calculator with Bitwise Operations](https://github.com/Spencer695/RPN-Bitwise-Calculator)** — A stack-based 16-bit calculator with addition, bitwise operations, validated CSV fixtures, CMake and Linux CI.

## Python and application projects

- **[Ask the Shop](https://github.com/Spencer695/ask-the-shop)** — A help-desk assistant with interchangeable retriever classes, PyTorch embedding fine-tuning, cited answers, an evaluation harness and 32 pytest tests.
- **[Monday Recap](https://github.com/Spencer695/monday-recap)** — A browser application that turns Shopify order exports into weekly sales reports. Report calculations are checked against independent pandas results. [Try the demo](https://spencer695.github.io/monday-recap/).
- **[NYC Flights Data Pipeline](https://github.com/Spencer695/nyc-flights-pipeline)** — A Python and SQL pipeline for 435,352 flights, with 16 data-quality checks, record quarantine and an atomic DuckDB warehouse publish.
